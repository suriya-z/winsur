## 一、产品概述

### 1.1 产品名称
**Vibe Island Win** (暂定)

### 1.2 一句话描述
Windows 屏幕顶部的浮动面板，实时监控和管理多个 AI 编程代理。

### 1.3 目标用户
- 使用 Claude Code / Codex / Cursor 等 AI 编程工具的开发者
- 同时运行多个 AI Agent 会话的高级用户
- Windows 10/11 用户（当前无竞品）

### 1.4 核心价值主张
> "不切窗口，掌控全局" — 在屏幕顶部一个浮动面板上管理所有 AI Agent，保持编码心流。

### 1.5 商业模式
开源（MIT License），面向社区。

## 二、功能规格

### 2.1 P0 - 核心功能（MVP）

#### F1: 灵动岛浮动面板
- 屏幕顶部居中的浮动面板，常驻置顶
- 默认折叠态：紧凑胶囊形状（约 300x40px），显示活跃 Agent 数量和状态指示灯
- 展开态：点击/悬停展开为完整面板（约 480x320px），显示所有 Agent 详情
- 支持拖拽调整位置（限制在屏幕顶部区域）
- 透明区域自动点击穿透

#### F2: Agent 会话监控
- 实时显示每个 Agent 的状态：idle（空闲）/ thinking（思考中）/ waiting（等待输入）/ error（错误）
- 每个 Agent 卡片显示：Agent 类型图标、会话名称、当前状态、运行时长
- 状态变化时有平滑过渡动画
- 支持展开单个 Agent 查看最近的工具调用

#### F3: 权限审批
- Agent 请求权限时，面板自动展开并高亮该 Agent
- 显示权限请求内容（工具名、操作描述）
- 提供 Allow / Deny 两个按钮
- 审批结果通过 HTTP 响应返回给 Agent
- 支持批量审批（全部允许/全部拒绝）

#### F4: 提问回复
- Agent 有问题等待用户输入时，面板显示问题内容
- 提供文本输入框让用户直接回复
- 回复通过 IPC 机制发送到对应终端

#### F5: 终端跳转
- 每个 Agent 卡片有"跳转"按钮
- 点击后聚焦到对应的终端/IDE 窗口
- 支持 Windows Terminal、PowerShell、cmd、VS Code、Cursor

#### F6: 系统托盘
- 最小化到系统托盘运行
- 右键菜单：显示/隐藏面板、设置、退出
- 左键单击：切换面板显隐
- 托盘图标根据 Agent 状态变化（有等待项时显示徽标）

### 2.2 P1 - 增强功能

#### F7: 音效提醒
- 不同事件有不同音效：权限请求、完成、错误
- 8-bit 合成器风格
- 支持自定义音效包（WAV 文件替换）
- 可在设置中开关/调节音量

#### F8: 零配置自动 Hook
- 首次启动时自动检测已安装的 AI Agent
- 自动写入对应的 hooks 配置（~/.claude/settings.json 等）
- 提供一键修复功能（如配置被覆盖）
- 卸载时清理 hooks

#### F9: Plan Review
- Agent 生成计划时在面板中渲染 Markdown 预览
- 支持 Approve / Reject plan

#### F10: 设置面板
- 支持的 Agent 开关
- HTTP 服务器端口配置
- 音效开关和音量
- 开机自启动
- 面板位置和大小
- 主题（深色/浅色）

### 2.3 P2 - 未来功能

- Token 用量统计和成本分析
- 会话历史回放
- 多显示器支持
- 快捷键系统
- Agent 分组管理
- 通知过滤规则

## 四、用户故事

### US1: 多 Agent 监控
> 作为开发者，我同时开了 3 个 Claude Code 分别处理前端、后端、测试。我想在一个面板上一眼看到它们各自在做什么，而不是来回切 3 个终端窗口。

### US2: 快速审批
> 作为开发者，Claude Code 请求执行 `rm -rf node_modules` 的权限。我不想切到终端去找那个窗口，我希望在面板上直接看到请求内容并点 Allow。

### US3: 即时回复
> 作为开发者，Agent 问我"用 PostgreSQL 还是 MySQL？"。我想在面板上直接输入"用 PostgreSQL"而不是找到那个终端窗口。

### US4: 精准跳转
> 作为开发者，我看到后端 Agent 出了错误，我想一键跳到它所在的终端窗口查看详情。

### US5: 不打扰编码
> 作为开发者，面板平时只显示一个小胶囊，不遮挡我的代码编辑器。只有需要我注意时才展开。

## 六、排除项

以下明确不在 MVP 范围内：
- macOS / Linux 支持（虽然 Tauri 跨平台，但 MVP 只做 Windows）
- 云端同步
- 团队协作功能
- 内置终端模拟器
- AI Agent 的完整 GUI 客户端（我们做的是覆盖层，不是替代终端）
