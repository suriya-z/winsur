## Known gaps

- **The installer already on GitHub is not this file.** The asset uploaded to
  the `v0.1.2` release has SHA-256 `41de3dafc2aff830b7438c61ea63e5a5f2205dbcf6ede6cfe59962adf62119dd`.
  It was built from the working folder, where Tailwind v4 also scanned the then
  untracked `tasks/` notes and added three unused CSS rules (`.fixed`, `.block`,
  `.table`). The JavaScript is byte-identical. When GitHub is reachable again,
  replace that asset with the file above.
- **Build from a clean worktree, not the working folder.** Tailwind v4 picks up
  class names from any file git does not ignore, so stray files change the CSS.
- **Renderer libraries ship twice.** All 8 `dependencies` (react, motion,
  lucide-react, ...) are bundled by Vite into `dist/` and also packed into
  `node_modules/` (about 6,400 files). The main process uses only Node
  built-ins and `electron`. Left as is for v0.1.2 by decision.
- **No auto-updater.** The app does not use `electron-updater`, so
  `latest.yml` and `.blockmap` serve no purpose; only `Winsur-Setup.exe`
  needs uploading.
